## Что нужно от интерфейса по контракту движка

Каждое замечание приходит с полями (`../contracts/engine-api.md`):
- **тип** — формулировка, дубль, противоречие, затронуто правкой;
- **светофор** — красный (уверенно) или жёлтый (модель сомневается — «проверьте»);
- **цитата** места и, для дублей и противоречий, **второй фрагмент** со статусом;
- **объяснение** одним предложением и правило (ISO/IEC/IEEE 29148);
- **предложение правки** «было → стало» (для формулировок — шаблон `<…>`, который заполняет человек);
- **вопрос** к бизнесу или технике — для списка «Что уточнить».

Решения команды (24.10): ревью по кнопке, а не в фоне; автофикс — за рамками MVP;
отключение типа замечаний целиком; отклонение отдельного замечания.
