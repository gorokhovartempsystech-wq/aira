# 0001. Десктопное приложение с локальными моделями

**Контекст.** Клиентам (банки, аутсорс с NDA) нельзя отдавать документы во внешние сервисы.
Облачный Atlassian в РФ недоступен. Генеративная LLM на обычном ноутбуке думает 8–11 с на пару
«изменение — фрагмент» (замер 25.10) — для интерактивной работы слишком медленно.

**Решение.** Десктопный редактор. Анализ — небольшими энкодерами в ONNX int8 на CPU (2–20 мс на
пару, пакет ~400 МБ). Генерация длинного текста (ТЗ из протоколов) — не в MVP: требует LLM
(уровень Pro с видеокартой или сервер компании).

**Последствия.** Документы не покидают компьютер — сильный аргумент для ИБ. Своя модель
(гипотеза H2 НИР) становится условием продукта. Нужны: упаковка движка в бинарник, загрузка
моделей при первом запуске, подпись кода.
