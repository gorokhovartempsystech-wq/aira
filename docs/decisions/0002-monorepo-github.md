# 0002. Один репозиторий на GitHub, задачи в GitHub Projects

**Контекст.** Команда из трёх человек: приложение, движок, дизайн. Связывает их контракт API.
Гайд НИР 3 требует выложить код в git.

**Решение.** Один приватный репозиторий: `app/`, `engine/`, `contracts/`, `design/`, `docs/`.
Задачи — GitHub Projects (доска «AIRA»), ветка + PR + ревью владельца папки, `main` защищён.
Проверки движка — GitHub Actions. Веса моделей — GitHub Releases.

**Последствия.** Изменение контракта и обеих сторон — в одном PR. Всё в одном месте для
научрука и комиссии. Нужны GitHub-аккаунты у всех троих.
