# 0004. Реальные документы компаний — только локально

**Контекст.** Для проверки модели нужны реальные документы (требование гайда НИР). Рабочие
документы компаний не обезличены, права на их использование не подтверждены.

**Решение.** Реальные документы — только на компьютере того, кому их дали: не в репозиторий,
не во внешние LLM (GigaChat, ChatGPT и т. п.), не в общие чаты. Обработка — локальными моделями.
В репозитории — только синтетика (с записью происхождения) и публичные наборы с лицензией.

**Последствия.** Сравнение своей модели с облачной LLM на реальных документах компаний невозможно —
только на публичных наборах (D12) и синтетике. Сам факт ограничения — довод за локальную модель.
