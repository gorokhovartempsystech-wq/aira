# 0003. Движок — отдельный процесс с локальным HTTP и токеном

**Контекст.** Приложение (Electron/Tauri) и ML на Python развиваются разными людьми и разным темпом.

**Решение.** Движок запускается приложением как дочерний процесс, слушает только 127.0.0.1,
печатает первой строкой порт и одноразовый токен; каждый запрос — с заголовком `X-Aira-Token`.
Контракт — `contracts/engine-api.md` и JSON Schema; примеры — реальные ответы движка, тесты
сверяют их со схемой.

**Последствия.** Приложение не зависит от Python-стека; модель можно обновлять отдельно.
Страница в браузере пользователя не может обратиться к движку без токена.
