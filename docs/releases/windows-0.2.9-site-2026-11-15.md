# Windows 0.2.9 — ручная публикация на сайте

Задача WIN-SITE-029, 15 ноября 2026. Прямой запрос Никиты в чате: опубликовать уже собранный Windows 0.2.9 на сайте сразу, проверку на настоящей Windows выполнит Артём позже. Это разовое решение о ручном скачивании; штатные критерии нативной приёмки автоматического выпуска не меняются.

- Новый EXE собран на Mac из main `ec7d12a0a04e32963f55673c08669f6ec5dd703c`, включая PR №25, с текущим кодом и защищённой моделью. Inno Setup 6.7.1 через Wine 11.21, Windows Python 3.12.10 x64 и PostgreSQL из закреплённой сборки 0.2.8; рабочие зависимости соответствуют текущему lock-файлу.
- Файл: [AIRA-Setup-0.2.9.exe](https://51.250.81.70/downloads/AIRA-Setup-0.2.9.exe), 501069582 байта.
- SHA-256: `a4ceb374cbb3c328c35d5ce76422a196b6836d399a6d499dcf6414f799d49d84`.
- Проверено 792 исходных файла по Git blob SHA, загрузка библиотек модели Windows Python, предкомпиляция, 15 регрессий launcher/startup через Wine, чистая пробная установка и SHA-256 всех 8429 подготовленных файлов.
- Установщик подписан существующим Ed25519-ключом обновлений. Подпись Microsoft Authenticode отсутствует.
- Сайт показывает Windows 0.2.9 / 501 МБ. Mac 0.2.9 сохранён. Каналы обновлений и `updates/releases.json` этой публикацией не меняются: Windows остаётся 0.2.8 до нативной проверки Артёмом. Новая сборка доступна вручную.
- Публикация выполняется вручную из-за квоты GitHub Actions. Перед переключением сохраняется снимок пяти файлов и обоих каналов; переключается указатель сайта, с откатом при ошибке HTTPS-проверки. GitHub workflow не считается прошедшим.
- `bash scripts/check.sh` в общей рабочей копии остаётся красным на трёх прежних E501 в `src/ara/model_protection/bundle.py` (54, 90, 107). Эти локальные файлы не используются в кандидате; полный общий gate зелёным не объявляется.

Артём проверяет установку/обновление на Windows 10/11 x64, запуск через WebView2, активацию, анализ, DOCX, сохранность документов и повторный вход. После успешной приёмки можно отдельно продвинуть этот же EXE в подписанный Windows-канал.
