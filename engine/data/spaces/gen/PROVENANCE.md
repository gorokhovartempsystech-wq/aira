# Происхождение обучающих пространств

Все пространства в этой папке — синтетические, только для обучения (`split: train`),
в тестовую выборку не входят. Здесь записано, чем и как сгенерирован каждый файл, —
для воспроизводимости и для раздела «Данные» в методике.

| файлы | генератор | способ | дата |
|---|---|---|---|
| `bank-limits.json`, `hotel-booking.json`, `food-delivery.json`, `online-courses.json`, `hr-vacation.json` | GigaChat-2-Max (API Сбера) | `aira_ml/generate.py`: сначала фрагменты, потом карта фактов по ним; автопочинка по правилам (журнал в поле `repairs`) | 2026-10-06 |
| `*-v2.json` | GigaChat-2-Max (API Сбера) | `aira_ml/generate.py --planned`: сначала план фактов, потом текст фрагментов по плану | 2026-10-06 |
| `*-c.json` | Claude (Anthropic), через агентов Claude Code | описание задачи в формате пространства «Возвраты»: 45–55 фрагментов, 8 фактов, упоминания трёх видов, ловушки шести видов; самопроверка генератором | 2026-10-06 |

Сырые ответы GigaChat — в `_raw/`. Разметка всех пространств независимо проверяется
учителем (GigaChat-2-Max, `aira_ml/teacher.py`); в обучение идут пары, где разметка
генератора и учителя совпадает.
