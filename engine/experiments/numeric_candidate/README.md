# Numerical research snapshot

Opt-in candidate, separate from the default backend engine. The default engine uses
stable isolated NLI, but does not import this directory. Import `numeric_v4.compare`
for structured numerical evidence, or `engine.Engine` for the research pair filters.

The v1–v4 files preserve the tested research dependency chain. They are not a
training pipeline or a claim of a universal numerical parser. Unknown bindings,
unsupported conditions and modality can abstain. Complemented equalities are
represented as unions of intervals. Numeric compatibility cannot cancel a separate
semantic claim. No document/customer data or model weights are stored here.

See `docs/research/ml-candidate-20261105.md` from repository root for measured scope
and remaining limitations. Run tests from `engine`: `python -m pytest -q`.
