# AIRA — экран скачивания

Локальный дизайн-прототип F01 по запросу от 5 ноября 2026. Независимая статическая страница без сборки, зависимостей и внешних запросов. Открыть `index.html` в браузере или запустить из этой папки:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:4173`.

Буквы появляются последовательно, фон медленно движется и реагирует на указатель мыши. Системная настройка уменьшения движения отключает эффекты. На обычном экране компьютера и портретном телефоне страница помещается без прокрутки; при увеличении текста или очень низком окне содержимое остаётся доступным с прокруткой.

Кнопки Windows/macOS открывают честное сообщение о подготовке релиза. Файлы установщиков, версии, размеры, совместимые процессоры и минимальные требования ещё не подключены. Никакой загрузки, регистрации, отправки данных или серверной логики здесь нет. Перед выпуском нужны проверенные установщики, реальные сведения о релизе и замена информационных кнопок ссылками скачивания.

Продуктовый источник: `../../docs/current-product-scope.md`. Публикация не выполнялась.

Проверено 5 ноября 2026 в браузере: 1280×720, 1440×900, 1366×768, 1024×768, 390×844 и 375×667 — без горизонтальной и вертикальной прокрутки. Проверены обе кнопки ОС, окна «О приложении» / «Перед установкой», закрытие кнопкой и Escape с возвратом фокуса. В консоли нет предупреждений и ошибок.
