# AIRA — сайт скачивания


Статическая страница: `index.html`, `styles.css`, `app.js`. Сборщик и внешние библиотеки не нужны. Установщики не добавляются в Git; папка `downloads` исключена.

Публичные ссылки используют HTTPS-сервер AIRA `https://51.250.81.70`. Домен пока не выбран. Mac: 0.2.6, Apple Silicon, macOS 14+, модель и адрес лицензий встроены; Sparkle получает следующие подписанные обновления. Windows: оригинальный пилот Ани 0.2.0, SHA-256 `01717fdeadcdb2ea5aa057e9e4330a2b6941167d962686ec5a439e549771a9fa`. Он ещё без лицензирования и автообновления. Новая Windows-сборка с updater требует сборки и нативной проверки на Windows. Intel Mac и Windows ARM не объявляются доступными.

В `Caddyfile` сохранены действующие маршруты лицензий и добавлена выдача только публичных файлов из `/srv/aira-public`. Файлы `.part`, исходники, конфигурация, секреты и листинг каталогов не выдаются. TLS проверяется обычным системным хранилищем, самоподписанного сертификата нет.

Перед публикацией проверить установщик, загрузить с суффиксом `.part`, сверить SHA-256 и переименовать. Только затем менять appcast и страницу. В `downloads/` положить оба установщика и `.sha256`; в `updates/` — подписанный Mac appcast. Windows appcast остаётся пустым, пока новая сборка не пройдёт нативную приёмку.

Не копировать репозиторий целиком в webroot. Публикуются только HTML/CSS/JS сайта, favicon, сведения о лицензиях компонентов, установщики, контрольные суммы и appcast. Перед перезагрузкой Caddy выполнить `caddy validate --config /etc/caddy/Caddyfile`. Для замены конфигурации сначала сохранить её резервную копию. Секреты подписи остаются только в `~/secrets.env` оператора, на сервер их не отправляют.

Процесс релиза: [подпись и обновления](../../app/frontend/packaging/updates/README.md). Merge PR не запускает доставку новой версии пользователям.

Локальное превью: `python3 -m http.server 4173 --bind 127.0.0.1 --directory sites/aira-download`. Кнопки используют публичный сервер и работают при размещении страницы на другом домене. Проверять desktop и мобильную ширину, обе ссылки и окна справки. Сведения о проверках конкретной сборки — в PR.

Проверка 12 ноября 2026: минимальная macOS повышена до 14 по реальным Mach-O зависимостям ONNX Runtime/SciPy. Опубликованная 0.2.6 пока содержит устаревшее `LSMinimumSystemVersion=13.0`; исправление сборщика применяется к следующему выпуску. Переименование системного требования на сайте не означает пересборку DMG. `codesign` показывает ad hoc, Gatekeeper отклоняет сборку, ticket Apple отсутствует. Для устранения блокировки нужны Developer ID Application, подпись вложенных исполняемых компонентов, notarization и stapling. Sparkle Ed25519 проверяет обновления AIRA и не заменяет подпись Apple. Команда пока не имеет Apple Developer (ответ Никиты 12 ноября).
