# app — десктопное приложение

Владелец: Никита. Стек выбирает владелец (Electron или Tauri); ниже — что нужно от приложения,
чтобы работать с движком.

## Как приложение работает с движком

1. При старте запускает движок дочерним процессом:
   `python -m aira_ml.engine serve --models <пакет моделей> --port 0`
   (в поставке — собранный бинарник движка, Python пользователю не нужен).
2. Читает **первую строку stdout**: `{"ready": true, "port": …, "token": …}`.
3. Все запросы — на `http://127.0.0.1:<port>` с заголовком `X-Aira-Token: <token>`.
4. При выходе из приложения — завершает процесс движка.

Контракт: `../contracts/engine-api.md`, примеры: `../contracts/examples/`.

## Что в MVP (из `docs/product/mvp.md`)

- Редактор: вставка текста (главный способ), импорт `.md` и `.docx`.
- Кнопка «Ревью» → `/v1/review` → справа панель замечаний: тип, светофор (красный — уверенно,
  жёлтый — «проверьте»), объяснение, цитата второго фрагмента.
- Кнопка «Исправить» у замечания → `suggestion.before → after`, с отменой (история правок).
- Отключить тип замечаний целиком, отклонить замечание → передаём в `disabled_types` и `dismissed`.
- Кнопка «Проверить влияние правки» у изменённого пункта → `/v1/impact`.
- Список «Что уточнить» из `questions[]`.

## Подсветка в тексте

`span.start/end` — позиции внутри текста фрагмента; в документе: `fragment.offset + span.start`.
Фрагменты берите из `/v1/parse` и передавайте в `review` и `impact` как `fragments`, чтобы `id`
не менялись между вызовами.
