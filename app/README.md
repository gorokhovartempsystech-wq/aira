# Приложение: текущий MVP и интеграция ML

Один документ, локальная проверка по кнопке, ручное исправление, повторное ревью, импорт и экспорт DOCX. Память скрытия относится к приложению; автоисправления и Merge не входят в текущий MVP.

Проверенный backend опубликован в [backend/](backend/). Начать с [PUBLICATION.md](backend/PUBLICATION.md): source snapshot4999b57, 2704 tests +24 subtests, ограничения и запуск. Реальная интеграция с текущим ML пока не выполнена; различия формата ответа описаны в handoff.

## Интеграция движка

1. Запустить `python -m aira_ml.engine serve --models <pack> --port 0`.
2. Прочитать первую JSON-строку stdout с портом и токеном.
3. Обращаться к localhost с заголовком `X-Aira-Token`.
4. Передавать фрагменты со стабильными ID и отображать позиции замечаний относительно фрагмента.

Контракт: [engine-api.md](../contracts/engine-api.md). В Python API `review` доступны progress, deadline и отмена через `Cancelled`; сетевой протокол очереди/отмены backend ещё требуется согласовать. Эти возможности Python API нельзя считать готовой интеграцией worker.

## Прототип ML

`python -m aira_ml.proto --models <pack> --port 8780` из `engine/`. Данные сохраняются локально. Есть ход проверки, остановка, частичный результат, фильтры, автосохранение и минимальный DOCX-экспорт. Экспорт создаёт файл заново и не доказывает сохранность оформления оригинала. Блок влияния правки экспериментальный.
