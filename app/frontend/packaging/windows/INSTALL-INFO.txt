AIRA — установка приложения

В выбранную папку будут установлены:
• редактор AIRA и локальная модель проверки требований;
• Python и библиотеки — среда для запуска приложения и модели;
• PostgreSQL — локальное хранилище документов, черновиков и результатов;
• WinSparkle — проверка и установка подписанных обновлений.

Эти компоненты уже включены в пакет. Самостоятельно устанавливать Python и
PostgreSQL не требуется. Для окна приложения нужен Microsoft Edge WebView2 Runtime.

Требования анализируются на вашем компьютере. Интернет нужен для проверки лицензии
при запуске и получения обновлений. Первый запуск включает подготовку хранилища
и проверку целостности файлов модели. Точные этапы отображаются в окне запуска.

Данные пользователя сохраняются отдельно, в %LOCALAPPDATA%\AIRA. Папку программы
можно выбрать на следующем шаге. Для пути программы используйте латинские буквы; смена этой папки не переносит пользовательские данные.

Пилотный установщик пока не подписан сертификатом издателя Windows. SmartScreen
может показать предупреждение о неизвестном приложении. Не отключайте защиту
Windows. Подробности о текущей сборке и её компонентах доступны на сайте AIRA.
