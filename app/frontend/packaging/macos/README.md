# AIRA для macOS. Пилот Apple Silicon

Сборщик принимает заранее подготовленный каталог с arm64 Python 3.12 и его зависимостями, PostgreSQL 18, backend, frontend и настоящей моделью 0.2m. Схема каталога соответствует проверенной локальной сборке.

```text
payload/
  python/bin/python3.12
  python/lib/
  pgsql/bin/
  pgsql/lib/
  pgsql/share/
  app/backend/src/
  app/backend/migrations/
  app/backend/alembic.ini
  app/backend/ml_bundle/
  app/frontend/static/
```

Из рабочего дерева с актуальным frontend:

```sh
python3 app/frontend/packaging/macos/build.py --payload /absolute/path/to/payload --sparkle /absolute/path/to/Sparkle-2.10.1 --version 0.2.4 --build 3 --output /absolute/path/to/AIRA-0.2.4-apple-silicon.dmg
```

Открыть образ и перенести AIRA.app в папку приложений. Пилот использует локальную подпись для проверки целостности. Для распространения готовится отдельная подписанная поставка.

## Активация

Адрес `https://144.124.235.162` встроен в установщик из публичного `release-config.json`. Пользователь ничего не настраивает: при первом запуске вводит ключ. Старый `license-origin.txt` в профиле не переопределяет адрес установщика. Клиент проверяет сертификат и имя хоста, затем привязывает введённый ключ к устройству. Повторный запуск проверяет сохранённую активацию через тот же сервер. База документов, сведения активации и журнал остаются в каталоге данных приложения.

## Обновления

С 0.2.4 Sparkle автоматически проверяет и скачивает подписанные обновления. Установка завершается после сохранения правок и закрытия backend. В меню приложения есть ручная проверка. Для пользователей 0.2.3 и ниже первый переход — вручную. [Сборка SDK, подпись и публикация](../updates/README.md).

Оператор поднимает сервер по [инструкции лицензирования](../../../backend/docs/license-server.md), настраивает HTTPS и создаёт ключ на нужный срок. Настройки с секретами передаются при явном запуске сервера. Приложение получает только адрес сервера и введённый ключ.

## Проверка установленной копии

Перенести приложение из образа в отдельную папку и открыть. С действующим сервером активировать ключ, импортировать DOCX, выполнить анализ, сохранить DOCX, закрыть окно и запустить AIRA заново. Затем проверить отключённый сервер на новом запуске. Экраны, диалоги и подпись проверяются на целевой ОС. Параметр `--smoke` проверяет загрузку экрана активации в WebKit для чистой папки данных.
