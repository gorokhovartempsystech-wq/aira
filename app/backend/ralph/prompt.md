# Инструкция исполнителю одного цикла

Ты работаешь над одной задачей AI Requirements Assistant. Прочитай корневой `AGENTS.md`, обязательный `docs/current-product-scope.md`, выбранную задачу из `ralph/tasks.json` и её точный контракт. Прежняя спецификация и бэклог применяются только в непротиворечащих текущему объёму частях. ID задачи, текущая попытка и её границы передаются runner. Если ID не указан однозначно, остановись с объяснением.

1. Проверь текущие файлы и учти изменения других исполнителей.
2. Реализуй только выбранную задачу в разрешённых путях. Сохраняй критерии приёмки и существующие проверки.
3. Выполни `bash scripts/check.sh`. Если проверка не проходит, исправь причину в пределах задачи. Не меняй проверку или зависимости ради зелёного результата.
4. Верни финальный JSON в схеме, переданной runner: `status` (`complete`, `continue` или `blocked`), `summary` (изменения и результат проверки), `completed_criteria` (номера выполненных критериев, начиная с 1), `blockers` (список конкретных препятствий). `complete` допустим только при выполнении всех критериев и успешной проверке. Не указывай выполненным критерий, который не проверял. Успешный ответ без проверки не считается выполнением.

Не редактируй task status и `ralph/progress.jsonl`: runner записывает журнал и состояние после своей проверки. Не запускай следующий task или вложенный цикл, не делай commit/push/deploy. Не читай архив рабочих документов и локальные отчёты по нему для начальной задачи. Не ищи или не выводи секреты и не меняй авторизацию. Не обходи ограничения sandbox или разрешений.

Конкретный ID и разрешённые пути задаёт выбранная задача, а не исторический порядок T01–T03. Инфраструктура, контракт и независимая приёмка подготовлены снаружи цикла. Не возвращай отложенные Merge/preview/apply, обязательные аккаунты и интеграции из старого плана. Не исследуй output/, .artifact-build/ или рабочий архив: для цикла достаточно разрешённых исходников, контрактов и синтетических тестов. Следующие задачи запускаются отдельно после подготовки их окружения и проверки границ.
