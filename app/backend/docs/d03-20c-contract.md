# D03-20C — символ и простая формула из командного примера

9 ноября 2026. F06/F08/F11. Продолжение проверки файла
`app/frontend/dev/pages/sample-blockers.docx` из PR19, commit
`ad02b9e475ad0dbad53fc9d3f2a12c019ad4564c`. Это синтетический файл команды,
не отсутствующий исходный Word for Mac. Его точная копия —
`tests/fixtures/docx/word-blockers.docx`.

Разрешённые изменения: `docx_analysis/visible_word` (закрытые glyph/math readers),
новый `test_docx_word_atoms.py`, указанный синтетический fixture, документация
и enum `slice.kind` в двух схемах DOCX review v5. Последнее необходимо, чтобы
результат с новым исходным атомом соответствовал опубликованной JSON Schema.
Схемы старых профилей, SQL, маршруты и прежние тесты не меняются.

- Поддерживается только доказанный символ Wingdings 252/F0FC: U+2713.
  Это `symbol` с адресом исходного `w:sym`, а не символ private-use Unicode.
  Неизвестные шрифты/коды не угадываются и вызывают отказ всего анализа.
- Поддерживается inline `m:oMath` из последовательности `m:r/m:t` с закрытым
  набором свойств. Вложенные дроби, степени, матрицы и произвольные свойства
  пока не линейризуются. Формулы не вычисляются.
- Скрытые Word runs исключаются; математический текст внутри кода поля
  исключается тем же автоматом, что обычный текст. Исходные адреса `m:t`
  сохраняются, включая Strict/UTF-16.
- `slice.kind` в review/result и presentation v5 получает `symbol` и
  `nonbreaking_hyphen` (последний нужен D03-20B). Старые значения и поля
  сохраняются. Клиент должен использовать адрес и цитату, не предполагать,
  что у каждого текстового атома XML-тег `w:t`. Обновление backend и клиента
  необходимо поставлять согласованно; старый клиент с закрытым enum не
  объявляется совместимым автоматически.

Проверки: red/green; исходные адреса, скрытие и поля; ошибочные/неизвестные
элементы; точный командный пример; сохранение и повторное чтение результата
через codec и presentation; соответствие новым enum JSON Schema. Общая
регрессия проводится после последовательности циклов.

Источники: [семантика w:sym](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.symbolchar?view=openxml-3.0.1),
[Wingdings 252](https://support.microsoft.com/en-gb/word/insert-a-check-mark-symbol?nochrome=true),
[структура math run](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.run?view=openxml-3.0.1).

VML, составные формулы и полный каталог шрифтов этим циклом не покрываются.
