# D03-17A2b2a1 — текущие и исторические direct properties

1 ноября 2026, Sol 6.1 High, после b1 `6cce155`. F06/F11, часть b2a по [дизайну](d03-17a2b-design.md). Одна задача: opt-in reader pPrChange/rPrChange без исполнения исторических свойств и без изменения результата b1. Policy Final/comments прежняя; visibility/стили в этом цикле не разрешаются.

Основание формата: [ParagraphPropertiesChange](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.paragraphpropertieschange?view=openxml-3.0.1), [RunPropertiesChange](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.runpropertieschange?view=openxml-3.0.1), прочитаны 1 ноября. History содержит предыдущее состояние; current properties расположены отдельно. Не переносить старый paragraph mark в текущее решение о границе.

Allowed: новые `final_view/properties.py`, `_properties_reader.py`; `_reader.py` только default-false hook для property history, `_build.py` только shared private builder с явным reader/profile и неизменным b1 wrapper, `_manifest.py` только profile argument/default b1 для fragment digest, `_map.py` только dispatch двух конкретных profiles и validation нового excluded record, `final_view/__init__.py` только новый export. `_models.py`/DTO shape/FinalViewLimits, A1/A2a/projection/native/editor/БД/dependencies/старые tests/scripts/runner/tasks/progress/AGENTS неизменны. Новая frozen `tests/acceptance/test_docx_property_history.py`, own `tests/docx_documents/test_property_history*.py`; этот контракт до freeze, result/queue и статусы/ссылки дизайна. current-product-scope.md только прямое решение Никиты сегодня о скрытом тексте/дата, без объявления реализации. Main V8 не мигрировать; локальные commits без push разрешены. Freeze→red→source→targeted/full→baseline→result/commit, без изменения frozen приёмки.

API `build_properties_snapshot(data, *, document_id, storage_revision, source_sha256, limits=None) -> FinalSnapshot`, те же exact inputs/errors/limits/grammar/coverage/mapping semantics b1, кроме явно заданных additions ниже. Profile `docx-analysis/final-properties-v1`, policy та же. Build_final_snapshot по умолчанию остаётся final-main-v1 и блокирует histories как прежде; никакого нового caller profile/reader argument в публичном b1 API. Map_final_span валидирует два конкретных profiles, не неизвестную строку; старый профиль не принимает новый record. Fragment ID canonical keys прежние, но profile берётся от explicit builder; manifest сохраняет exact новый profile. Даже same source/text при разных profiles имеет разные fragment IDs/snapshot digest. Public imports инертны, старый top-level ara.docx_analysis/__init__ не меняется.

Новая grammar: внутри **текущего** pPr допускается один pPrChange, внутри текущего rPr (run или paragraph mark) — один rPrChange. Hook вызывается после duplicate-child check. Context должен точно соответствовать имени; другие *Change и histories внутри numPr/sectPr не поддержаны. History wrapper требует тот же decimal w:id, что b1 revision, whitespace-only direct text/tails и ровно одного child: pPr для pPrChange, rPr для rPrChange, в namespace документа. Empty/multiple/wrong child/namespace, missing/bad id, duplicate wrapper, tail text → unsupported_main_flow, без fragments. Current grammar целиком остаётся строгой: например, current vanish/fields/moves пока blocked.

Поддерево previous properties после проверки container формы **исключается целиком** из interpretation: не включать вложенный text, не принимать из него del/ins для boundary, не применять historical vanish/rFonts/style. Рекурсивный поиск в этом subtree запрещён, XML/node/depth/paragraph budgets до semantic pruning продолжают действовать. Это не полная проверка OOXML schema и не обещание исправить невалидный Word; неподдержанные элементы historical subtree не могут стать текущим текстом. Wrapper tail относится к активному property container и проверяется.

Для каждого посещённого history wrapper новый record `excluded/historical_properties`, anchor wrapper, part_name main, fragment_id=None. Старое свойство не получает supported_properties, а descendants не создают отдельных records. Остальные b1 coverage records/counting/sort semantics прежние. Для profiles final-properties-v1 validator разрешает historical_properties **только** с anchor как direct child распознанного supported_properties root; record должен быть внутри covered physical p и main flow. Не принимать новый record в final-main-v1, в part-level metadata или при unsupported flow. Все pieces не могут находиться внутри deleted_content **или historical_properties** subtree. Hash/ID/shape checks остаются обязательными, не полагаться на digest как на доказательство семантики.

Нельзя снимать блокировку auxiliary parts/hidden current properties по одному MIME или этому новому profile. Стилевые/visibility guards — отдельный b2a2; новые policy решения пользователя там фиксируются отдельно. Source original bytes не меняются, XML дерево не модифицируется ради удаления histories. Repr/error не раскрывают property payload/author/metadata; ни чтения env/файлов/БД/сети, ни upstream/model imports.

Приёмка: same source с run/p/paragraph-mark histories: новый reader выдаёт exact current text/ranges/joins, старый b1 остаётся incomplete; historic del не объединяет paragraphs, historic ins не отменяет current del. Nested historical fields/foreign text/hidden props не исполняются; current unknown properties продолжают блокировать. Malformed histories matrix, duplicate/wrong-context/IDs/tails, Strict/Transitional/UTF8/UTF16/renamed main, independent profile/manifest/fragment hashes, rehashed bad historical coverage/pieces, exact/+1 coverage и excluded subtree input budgets. Inert subprocess, legacy b1/A1/A2a regression, source preservation/full gate. Fixture не является real ML/Word QA.
