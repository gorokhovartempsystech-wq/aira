# D03-17E2B — постоянные фильтры и скрытие замечаний

3 ноября 2026. Реализован [контракт](d03-17e2b-contract.md): scoped чтение,
CAS-команды настроек/hide/unhide и проверяемые идемпотентные receipts на V13.
До первой записи возвращаются виртуальные defaults revision0 без создания строк.
Команды сохраняются атомарно, даже no-op получает новую revision; повтор старой
команды возвращает первоначальное подтверждение и не откатывает свежие решения.

Скрытие допускается только для проверенного результата того же документа.
B2/E1 decode выполняется вне SQL locks; перед записью повторно проверяются
ownership, revision и immutable origin. Ключи относятся к точному source; перенос
между изменёнными версиями ещё не реализован. Фильтры не меняют исходный результат
или запрос к модели. Повреждённые receipts/source/metadata отвергаются безопасно.
