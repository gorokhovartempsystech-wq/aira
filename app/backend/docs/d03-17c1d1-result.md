# D03-17C1D1 — continuous clock и наследуемая блокировка macOS

1 ноября 2026, Sol 6.1 High. Реализован [контракт D1](d03-17c1d1-contract.md), первый цикл [C1D](d03-17c1d-design.md). Новый subpackage `ara.docx_analysis_worker.macos` содержит explicit DarwinClock, pure integer conversion, RuntimeOwner/SlotLease и metadata-only ошибки. Никаких model/guardian/SQL calls при import или создании clock; native FFI загружается только при now_ns.

Continuous time использует mach_continuous_time/timebase, точное integer деление, signed63 bound и необратимый отказ при backward/native/overflow fault. Mutex сериализует чтение clock; live object после fork не переиспользуется. Нет fallback или второго guard.

Owner/slot открываются через проверенную цепочку directory FD без symlinks, с own UID/mode/type/nlink/size и inode checks. Постоянные lock files не удаляются и не изменяются ради успешной блокировки. Slot наследуется через pass_fds, явный LOCK_UN не используется. После закрытия родительского reference независимый open/lock проверяет наличие holder. Release failure не превращается в cleanup success. Abandon закрывает только собственные references; fd invalidation до close исключает повторное закрытие уже переиспользованного номера. Private issuance registry отвергает поддельные объекты даже с копией attributes; copy/pickle запрещены.
