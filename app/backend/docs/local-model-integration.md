# Локальная интеграция ML — 01.11.2026

Рабочая ветка `artem/ml-backend-integration-20261101` поверх backend 2607f04. Подготовлено к публикации отдельной веткой и PR; слияние с main проверяется отдельно.

## Сценарий

`/editor` использует оформление и компоновку макета `design/mockup-2026-10-03/new.html`: текст слева, замечания справа. Это адаптация статического макета, не полное подключение нового DOCX-controller/DOM/IME. Исходный макет сохранён. Интерфейс `/workspace` Никиты не заменён и не изменён.

Новый текст → сохранённый DOCX в PostgreSQL → snapshot точных байтов/версии → отдельный CPU ONNX-процесс → строгая проверка evidence → результат в PostgreSQL → замечания и вопросы. Редактирование вручную, повторная проверка, скачивание DOCX. Импортированный DOCX проверяется без перезаписи; правки его фрагментов пока через `/workspace`. Автоисправлений нет. Черновик редактора и ссылка на последний результат сохраняются в localStorage; сами завершённые результаты — в БД.

## Запуск

Нужны зависимости backend и `engine/requirements-engine.txt` в одной venv; PYTHONPATH включает `app/backend/src` и `engine`. Веса не скачиваются автоматически.

Установить `ARA_ENVIRONMENT=local`, `ARA_DATABASE_URL` отдельной PostgreSQL, `ARA_MODELS_DIR` к проверенному локальному pack. Выполнить `alembic upgrade head` ТОЛЬКО на подготовленной отдельной базе. Затем `python -m uvicorn ara.local:create_local_app --factory --host 127.0.0.1 --port 8000`.

Проверенная локальная база: Docker postgres:18, контейнер `aira-ml-pg-20261101`, network=none, только Unix socket `/root/tmp/aira-pg-integration`, БД `ara_ml_dev`. TCP не опубликован. Не удалять контейнер/его volume без сохранения документов. Секретов для этой изолированной тестовой базы нет. Это не схема production-развёртывания.

Для полного старого тестового gate на Docker используется явный `ARA_TEST_PG_DATA_DIR=/var/lib/postgresql/18/docker`; fixture по-прежнему сверяет путь БД и запрещает TCP, создаёт/удаляет только свои случайно именованные disposable databases. macOS-default не изменён.

## Контракт

Pinned `docx-review/1` и его validator не ослаблены. Новый внешний envelope `local-model-review/1` сохраняет `partial_reason`, `incomplete`, `checked.pairwise`, `seconds`, а внутри содержит source-validated результат. Лишние неизвестные поля запрещены. Неполный результат никогда не выдаёт `no_findings=true`. `pairwise` — число фрагментов после фильтра, НЕ число проверенных пар. Перебираются похожие кандидаты, не все пары. `partial` проверяется до адаптации и возвращается клиенту; не теряется.

Endpoints (только при явном ARA_MODELS_DIR):
- POST `/docx-documents/{id}/model-reviews`, JSON expected_revision (строка).
- GET `/docx-documents/{id}/model-reviews/{review_id}` — состояние/результат/outdated.
- DELETE тот же путь — остановка текущего процесса.
- POST `/editor/documents` — сохранить авторский текст как DOCX с expected_revision; импортированные файлы UI этим путём не перезаписывает.

Один процесс анализа за раз; повторный запуск возвращает 409. Жёсткое завершение дочернего процесса после 300 секунд; внутренний deadline 290 секунд после загрузки. Законченные результаты переживают перезапуск backend; running/failed/cancelled состояния пока только в памяти. Старый PostgreSQL worker остаётся fixture, он не используется этим opt-in DOCX-путём. Общий durable job lifecycle и автоматические retry пока не реализованы для нового пути.

## DOCX и ограничения

Reader принимает абзацы/заголовки собственного шаблона: `widowControl` признан свойством оформления, а settings/неиспользуемый numbering допускаются лишь при точном совпадении SHA256 с известными инертными частями шаблона и отсутствии numPr. Изменённые settings, нумерованные списки, таблицы и другие неподдерживаемые части не обходятся. Возвращается явный отказ, а не фиктивное «проверено».

Входной DOCX wire пока передаёт всем фрагментам active и не выводит статус из заголовка. Не использовать этот путь для доказательства качества на архивных/обсуждаемых требованиях. Форматирование импортированных документов не нормализуется. Привязка к цитате отображается; переход по цитате в текстовом редакторе выбирает первое совпадение, точное позиционирование повторов — дальнейшая интеграция editor controller.

Нет desktop-установщика, лицензирования, полной поддержки Word и готовой независимой экспертной оценки. ML остаётся pack0.2m, обучения в этом цикле нет.
