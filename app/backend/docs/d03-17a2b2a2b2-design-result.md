Выбраны отдельный visible-main profile/policy/DTO, точная main grammar, общий streaming XML budget до DOM, один catalog/index на build и XML-derived selectors/direct properties. Snapshot хранит immutable provenance без исходного ZIP/ET и пользовательского содержимого в repr. Hidden/deleted/history/comments не становятся source slices; quote через скрытый run возвращает несколько точных диапазонов без промежуточного скрытого текста.

Существенное решение mapper: original bytes обязательны, весь snapshot проверяется authoritative rebuild один раз на batch. Только после этого используются exact fragment offsets/quotes и индекс pieces. Это защищает от forged ranges/context/coverage даже при пересчитанных manifest hashes; сохранённую document identity всё равно проверяет будущий сервис. Старые mapper/DTO/manifest не переинтерпретируются. Ограничены aggregate XML, text, запросы, slices и canonical manifest bytes; отсутствие truncation/partial success входит в приёмку.

Новый integrated profile консервативно блокирует такой main и потенциально hidden/deleted paragraph marks. Ordinary-run algebra остаётся неизменной; boundary algebra не подменяется ей.
