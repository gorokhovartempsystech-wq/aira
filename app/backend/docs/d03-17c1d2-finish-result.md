Восемь source files D2 реализуют отдельный guardian и synthetic child с private pipes, prepared/gate/armed barrier, bounded control/stderr/status, minimal env/FD allowlist и isolated entries. Guardian единолично владеет retained unreaped child; TERM/grace/KILL, NOTE_EXIT и exact wait разделены. Старые PID не принимаются, signal не повторяется после ошибки/reap. Continuous clock и inherited slot — проверенный D1; guardian не получает SQL/DOCX/model credentials.

Readonly signal_error/hard_fault/aggregate различаются: нормальный Stop с actual wait без самостоятельного hard fault даёт stopped, хотя signal_error/fault остаются sticky. Без wait нет proof; unknown signal/native/clock/protocol/wait ошибки не маскируются. После Stop или signal error clean невозможен. Отменённый startup не требует больше ACK/GO; известный malformed token остаётся hard fault. Parent driver/SQL publication не включены в D2.

Дополнительно проверены partial pipe/spawn failure cleanup, canonical CLI/config, descriptor modes, process origin/issued handles, immutable env/readonly snapshots и late drain failure после signal race. Ошибка закрытия не повторяет close по переиспользуемому номеру. Model reply — явно synthetic `fixture-response`, не настоящий B1 анализ; источники/результаты пользователя не изменяются.
