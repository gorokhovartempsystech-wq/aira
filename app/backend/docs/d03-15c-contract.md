# D03-15C — plain-text paste и замена внутри одного абзаца

31 октября 2026, после f88407f. Sol 6.1 High; автономное продолжение Никита подтвердил. F05/F11. Один paste intent атомарно заменяет collapsed/однопараграфное выделение обычным текстом, включая новые paragraph boundaries и native TAB. Без HTML/rich clipboard, Shift+Enter/soft break, выделения между p, UI/DOM/IME и durable persistence.

## API

Новый frozen/slotted PasteLimits(max_text_chars=1000000,max_new_paragraphs=1000), оба поля положительные int без bool, frozen bypass проверять. EditorSession.paste_text(text: str, *, expected_revision:int, paste_limits:PasteLimits|None=None) -> прежний EditorSnapshot. Тип PasteLimits строгий; ошибки формы EditorError invalid_input. Limits превышены → прежний text_limit_exceeded. Export PasteLimits добавляется без изменения старых DTO/методов.

Revision проверяется первой. Anchor/focus должны относиться к одному body paragraph; reverse selection нормализуется в source lo/hi, multi-p selection даёт unsupported_intent без удаления данных. text — настоящий str. Предел code points проверяется по исходной строке до normalization. CRLF→LF, оставшийся CR→LF; другие Unicode code points без normalization. XML-safe text допускает TAB/LF, прочие XML-invalid controls/surrogates отклоняются. New paragraphs — количество LF после normalization, максимум inclusive max_new_paragraphs. Ничего не обрезать.

Каждый LF становится настоящей границей p; TAB — native Word tab, без буквальных TAB в t. Начальная/последняя пустые строки и повторные LF сохраняются. Это match-destination plain text: все p наследуют исходные pPr/style/list identity и не применяют w:next/выход из пустого списка. Пустые clipboard lines в списке остаются пустыми пунктами. Нумерация/стили parts не переписываются.

Сохранить old.text[:lo] в первом p и old.text[hi:] в последнем; runs/formatting исходных символов остаются прежними. Для inserted text единый direct run template: collapsed — B3 affinity; выделение — формат позиции lo с affinity right, не направление selection. Разные исходные styles не усредняются. Перенос namespaces и original/new p identity как D03-14. Вычислить один bounded lexical patch по исходному p, а не выполнять тысячу exports/исторических шагов. Guard/Node limits D03-14 и package/projection/session budgets обязательны. Прочие main ranges/ZIP parts/order/metadata прежние.

Последний пустой clipboard line получает empty typing run template до original suffix, чтобы последующий ввод имел определённый формат. Cursor после paste в последнем результате, offset=len(last_clipboard_line), affinity left; для одно-строчного paste offset=lo+len(line). Один paste/удаление — одна publication/revision/frame. Empty text при collapsed selection — полный no-op. Empty text при непустом выделении удаляет выделение и сохраняет p. Если одно-строчная normalized строка точно равна выбранному тексту, bytes/revision/ID/redo не меняются, selection только схлопывается в конец (кроме полного empty collapsed no-op). LF даже при равном paragraph.text не no-op: native soft break отличается от paragraph boundary.

Seed/direct formatting входит в package; дополнительных скрытых bytes/history нет. Ошибка текста/limits/стиля/пакета/after reply полностью сохраняет документ, курсор, saved mark и историю. Не удалять защищённые/opaque/range/annotation элементы ради замены: прежние gates дают отказ. Snapshot/limits не разделяют изменяемое состояние с caller. Импорт/операции без I/O/env/secrets/logs.
