# Текст внутри элементов управления содержимым Word

`ara.docx_analysis.visible_controls` предоставляет build_control_snapshot,
map_control_spans/span. Фиксированный профиль final-visible-rich-controls-v1 использует
прежний NoteSnapshot: исходные адреса, фрагменты и ссылки на сноски сохраняются.
Reader переиспользует общий pipeline и чтение полей, не меняя старые публичные API.

Поддержаны сохранённые unbound rich-text controls — явный richText и отсутствие
типа, которое означает richText. Block controls содержат абзацы/вложенные controls
в основном тексте, колонтитулах и активных сносках. Inline controls читаются внутри
обычных абзацев и абзацев таблиц. Исходный файл и реальные XML-адреса не изменяются.
Пустой/отсутствующий sdtContent не добавляет искусственные символы или абзацы.

Метаданные alias/tag/id/placeholder не становятся требованиями. Свойства будущего
ввода в sdtPr и свойства delimiter в sdtEndPr не применяются заново к сохранённым runs;
их реальная видимость разрешается по прежним стилям/прямым свойствам. Неизвестная
разметка не пропускается даже внутри скрытого содержимого. Незавершённое поле не
может пересечь control boundary; закрытые поля внутри и снаружи остаются доступны.

Привязка к custom XML, активный placeholder, plain-text и другие типы controls,
block/table/row/cell wrapper combinations и section/move cases за прежними границами
пока явно блокируются. Это не удаление данных и не догадка о видимом результате.
Ошибка активного содержимого оставляет snapshot без частичного текста и note links.

Raw control/field counts и control nesting проверяются до semantic DOM, также в
неиспользуемых и исключаемых branches. Mapping batch перестраивает snapshot из
исходника один раз, даже без запросов, и проверяет весь результат; интервалы считаются
по Unicode code points. Внешние данные не загружаются, источники не выполняются.

Полный application admission, редактирование сложных объектов, сохранность верстки
в Word и native Windows подтверждаются отдельными циклами. [Контракт](d03-17a2b5b1-contract.md)
содержит первичные источники; [результат](d03-17a2b5b1-result.md) — фактические проверки.
