## Оставшиеся границы

- Полный пользовательский сценарий через кнопки нативных окон этой приёмкой не
  подтверждён: Mac smoke проверяет экран, а анализ/экспорт проверены через тот же
  локальный API и установленный runtime. Для Windows предусмотрена отдельная
  пользовательская проверка Аней.
- Один Windows fixture со сроком lease 4 секунды однажды не вернул кандидата;
  повтор и следующий независимый запуск прошли. Критерии/сроки теста не ослаблялись.
  Это наблюдение сохраняется, несмотря на зелёный повтор.
- Поддержка сохранности данных не означает защиту от администратора/владельца
  процесса. Ключ/веса можно перехватить в памяти или изменить клиентский код.
  Ранее опубликованные открытые модели остаются открытыми.
