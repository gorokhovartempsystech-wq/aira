# D03-02 — результат просмотра содержимого DOCX

30 октября 2026. Реализован [контракт D03-02](d03-02-contract.md), часть F05/F11/F12 [текущего объёма](current-product-scope.md). **Полный `bash scripts/check.sh`: 1330 тестов и 24 подтеста проходят**, Ruff и форматирование проходят. В локальном экране теперь видны абзацы, текст и таблицы выбранного DOCX. Это упрощённый структурный просмотр без редактирования, не рендер страниц Word.

## Поведение

Новый GET `/docx-documents/{document_id}/view` получает один snapshot существующего хранилища и строит проекцию текущего файла. Возвращаются метаданные, body_anchor, blocks/notices, coverage_scope и has_unprojected_content. Поля доменных records проекции сохранены, включая ссылки на XML-элементы, Unicode offsets, properties anchors, style/numbering IDs, grid_span/vertical_merge, hyperlink references и opaque-причины. Raw DOCX, original hash, ZIP inventory и идентификаторы владельцев/проектов не возвращаются. Ревизия хранения передаётся десятичной строкой, включая MAX BIGINT, без потери точности в JS.

Проверяются прежнее владение, целостность хранения и отсутствие query-параметров. Handler синхронный, работает в threadpool, не пишет в БД и не закрывает caller engine. Новые модели Pydantic deferred, модули импортируются без I/O. OpenAPI содержит рекурсивную структуру и ошибки. Непредвиденные сбои построения нормализуются в безопасный storage_error, прежние DocumentError сохраняются.

Просмотр ограничен 5000 records, включая anchors/hyperlinks, суммой 1000000 Unicode-символов строковых полей проекции и 8 MiB JSON UTF-8. Превышение даёт целиком безопасный 413 view_limit_exceeded. Это технические бюджеты текущего просмотра: импорт и скачивание того же файла остаются доступны.

В UI после выбора/импорта запрашиваются свежие metadata и содержимое. Абзацы сохраняют пробелы и переносы, таблицы и вложенные таблицы отображаются структурно. Для объединений даны нейтральные подписи, нумерация/оформление Word не выдумываются. Непоказанные inline/блочные элементы обозначаются явно; предупреждение объясняет, что они сохранены в DOCX. Внешние ссылки не активируются; документ не становится HTML. Перед переключением прежний текст очищается. При отказе просмотра сведения и скачивание выбранного файла сохраняются; подтверждённый импорт не считается потерянным.

## Реальный браузер

Preview работал только на localhost с собственной disposable PostgreSQL. Использовались три synthetic DOCX:

- Контрольный rich-source.docx: после загрузки появились основной текст, таблица с устройствами и подпись непоказанного изображения. Есть явная пометка упрощённого просмотра; исходные bytes не переписывались.
- Документ с `<img onerror=alert(1)> Я🧪`, вложенной таблицей, gridSpan и opaque sdt: текст показан буквально, DOM содержит 0 img и 0 активных ссылок внутри содержимого; обе таблицы и подписи непоказанных элементов видны.
- Файл с 500001 повторяющимся символом: импорт подтверждён, просмотр корректно отказал по бюджету, старое содержимое очищено, скачивание доступно. Скачанный файл из браузера совпал с загруженным synthetic файлом побайтово.

Проверено переключение между тремя документами и возвращение к rich-source после отказа объёмного просмотра. На ширине 390 пикселей страница не имеет горизонтального переполнения; таблица прокручивается внутри своего контейнера. Screenshot на ширине 1280: `.runtime/d03-02-qa/view-desktop.jpg`. Временный viewport сброшен. Microsoft Word и точная вёрстка страниц не проверялись, новые рендеры DOCX не создавались.
