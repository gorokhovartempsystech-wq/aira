Три POST paths, scoped document UUID и canonical session UUID:

- `/docx-documents/{document_id}/editor-sessions/{session_id}/saved-content`: E1 control identity с **результирующими** command/session counters, registry.saved_target. Возвращает bytes именно последнего подтверждённого SaveTarget, а не последнего current в БД. Новый local intent делает target stale.
- `.../{session_id}/working-content`: strict body expected_command_sequence, expected_session_revision (canonical decimal strings), expected_sha256 (lower hex64). Новый registry.working_target проверяет текущие RAM counters/hash, returns WorkingTarget без изменения actor/history/CP/current. Работает при active/pending/conflict и повреждённом receipt/чужом CP: только project→document scope lock, без чтения receipt/current BLOB/checkpoint fence. Scope404 предшествует expired410. Под mutex повторно проверять живость actor; scope read commit должен успешно завершиться до reply.
- `/docx-documents/{document_id}/editor-recovery/content`: strict body expected_checkpoint_revision и expected_sha256. Новый registry.recovery_target — passive coherent transaction, project→document read lock→legacy/CP validation `_record`. Только working/pending, exact monotonic CP+hash; absent/empty/mismatch409. Не init/commit/finalize/discard/receipt lookup. Повреждённый package/metadata не выдавать как проверенный; valid pending bytes можно скачать при повреждённом receipt. RecoveryTarget detached, no bytes repr.

Все ответы DOCX MIME, exact bytes≤32MiB, no-store, quoted SHA256 ETag, Content-Disposition attachment с фиксированным UUID filename (saved .docx; рабочая -working.docx; черновик -recovery.docx). Headers X-ARA-Storage-Revision для saved, X-ARA-Command-Sequence/X-ARA-Session-Revision для working, X-ARA-Checkpoint-Revision для recovery, X-ARA-Copy-Kind saved/working/recovery. Не вводить JSON/base64 package или пользовательский filename. Binary construction в shielded worker, gate E2 охватывает send; read body≤64KiB с теми же strict transport checks. Неподтверждённая копия не выдаётся за сохранение.
