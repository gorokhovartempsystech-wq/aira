# Контейнеры Word вокруг таблиц

`ara.docx_analysis.visible_control_tables` предоставляет build_control_table_snapshot,
map_control_table_spans/span с фиксированным профилем final-visible-control-tables-v1.
Тот же NoteSnapshot сохраняет исходные адреса, интервалы и связи со сносками.

Unbound rich controls могут охватывать таблицу, отдельную строку или ячейку, а также
абзацы/вложенные таблицы внутри ячейки. Вложенные controls и обычные соседние элементы
читаются в исходном порядке. Непустой row/cell control представляет ровно один реальный
элемент; пустой не создаёт фиктивных строк, ячеек или символов.

Исходный XML не перестраивается. Private context сохраняет физических родителей
и отдельно доказывает логические связи через проверенные sdt/sdtContent. GridGeometry
получает настоящие исходные узлы; предыдущие правила current properties, retained
revisions, grid spans, vertical merges, regular inferred grid и table styles остаются.
Свойства нельзя спрятать в control или перенести после пустого wrapper, чтобы исправить
невалидную исходную структуру. Таблица в ячейке сохраняет настоящую ячейку-владельца.

Чтение идёт по физической иерархии. Flow абзаца — реальная ячейка либо body, включая
вложенные таблицы, колонтитулы и сноски. Пустые wrappers тоже создают границу для поля
Word; поле не может незаметно пересечь control или сменить ячейку. Сохранённые поля
в нескольких абзацах одного control внутри одной ячейки поддержаны. Непустой текст
merge continuation по-прежнему не теряется молча: такой случай явно блокируется.

Четыре маленьких private hooks переиспользуют общий код с прежними defaults; старые
публичные profiles не расширены. В новом reader только свежий source-derived proof
разрешает таблицы/истории/ревизии. Любая активная ошибка оставляет весь snapshot без
частичного текста. Batch mapping один раз проверяет исходный DOCX и точный snapshot,
включая пустой запрос. Все raw/semantic/output лимиты сохраняются.

Полнота DOCX, plain/bound/placeholder/прочие controls, MC, media/numbering, редактирование,
application admission и native Word/Windows проверяются отдельными этапами.
