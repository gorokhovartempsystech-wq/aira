# D03-17B1 — strict review wire и проверка ответа engine

1 ноября 2026, Sol 6.1 High. Реализован [контракт](d03-17b1-contract.md) в отдельном review package и новой [JSON Schema](../contracts/docx-review-v1.json). Исходники/контракты/tests прежних циклов не менялись. Это pure request/result validation по pinned engine0.1 source036a4e8, без импорта/запуска модели, HTTP, БД, нового UI или изменений weights/dependencies.

prepare_review source-backed проверяет pinned snapshot, complete coverage и наличие текста, затем строит точные active fragments (включая короткие строки/Unicode/hidden gaps), с пустыми disabled/dismissed. Wire docx-review/1 связывает document/revision/source SHA/snapshot/profile/policy и trusted attempt/model/adapter provenance. Legacy snapshots не становятся fallback; сложные unsupported DOCX остаются недопустимыми даже для fixture.

validate_engine_reply ограничивает bytes/depth до materialization, отвергает duplicate JSON keys/nonfinite/bool numerics/extras и проверяет pinned versions/checked counts/issue types/IDs/questions. Все primary/related spans проверяются одним source-backed mapping batch, включая empty results. Related обязан быть полным другим fragment; malformed issue отклоняет весь ответ. Transport request заново выводится из verified source/provenance без второго rebuild и сравнивается с переданным request. Source/view/package errors не маскируются под успешные пустые ответы.

Findings получают полные semantic SHA IDs, не upstream40-bit identity. Transport attempt/upstream ID/confidence/suggestion не меняют semantic ID, model/severity/evidence/explanation/question/rule меняют. Question dedup сохраняет все origin findings. Canonical internal result wire хранит exact source slices/coverage/counts; confidence/rule/suggestion остаются в private provenance, без auto-apply/ISO claim. Fixture всегда no_findings=false; отдельная synthetic protocol проверка local_model branch не является реальным inference и не подтверждает weights/качество модели. Future C2 выбирает и верифицирует фактический execution kind/pack.

Новые DTO frozen/slotted, wire bytes/sensitive metadata скрыты из repr. Prepared foreign DTO проверяется до equality; output encoding streaming с cap до append. Технические bounds только уменьшаются и revalidate на API, без clipping. Fresh-process prepare/validate прошли без application file/env/network/process/DB/model I/O. JSON Schema local refs, строгие object keys/required и semantic validator matrix проверены; сторонний Draft2020-12 validator в доступных Python environments не установлен, зависимости ради него не добавлялись.
