# Клиент лицензирования AIRA

D04-03, 4 ноября 2026. Модуль `ara.licensing.client` подключает D04-01 protocol к
серверу D04-02. Его конструкторы не читают файлы/секреты/устройство и не ходят в сеть.
Это библиотека для будущего desktop bootstrap; старый development app пока не
закрыт этой проверкой и не является готовым лицензированным приложением.

## Подключение

Trusted bootstrap передаёт HTTPS origin сервера и абсолютную app-owned папку
ActivationStore. Parent папки должен существовать; не использовать общую upload
папку или каталог документов. На Windows папку/ACL готовит установщик или bootstrap.
Production origin должен быть проверенной конфигурацией поставки, не полем из
браузера и не адресом, извлечённым из ключа. Реальный домен пока не назначен.

Создать `LicenseClient(origin, ActivationStore(root))`; один клиент на процесс.
`start()` запускает online check сохранённой активации. Если её нет, snapshot
переходит в `activation_required`; UI показывает поле ключа и передаёт его в
`start(key)`. Ключ существует только в оперативной памяти текущей попытки.
`start` возвращает snapshot сразу, состояние опрашивается через `view()`.
Синхронно читаются только короткие continuous clock; hardware/file/network работают
в отдельном daemon thread. Повторное нажатие с тем же ключом не создаёт второй запрос.

`phase=active` — текущее подтверждение. Перед каждым новым защищённым действием
bootstrap вызывает `require_active()`; он возвращает LaunchPermit либо фиксированную
ClientError. Просто сохранённый snapshot не служит разрешением. UI не должен сам
вычислять разрешение по expires_at_ms или системным часам. Срок проверяется через
continuous clock, включая сон; часы пользователя не продлевают допуск.

`failed` содержит error_code: network_unavailable, invalid_license,
device_mismatch, license_disabled, activation_store_error, device_unavailable,
clock_unavailable, verification_timeout либо другую фиксированную ошибку протокола.
`expired` означает license_expired. Snapshot не содержит ключ или сырой hardware UUID.
Локализованные подписи UI формируются по code, не из удалённого текста исключения.

## Повторы и закрытие

`retry_available=false` означает, что предыдущий worker ещё не завершился, либо
клиент закрыт. Тайм-аут наблюдаемого запуска15s не позволяет выдавать поздний допуск.
DNS/системный вызов может пережить socket timeout: нельзя создавать новые клиенты
для обхода ожидания worker. В одном клиенте одновременно максимум один worker.
Когда он завершился, явный `start()` повторяет online check; новая попытка всегда
получает новый nonce и очищает старый permit.

`close()` инвалидирует доступ, не ждёт неопределённо DNS/OS и не прерывает произвольно
файловую запись. Worker сам закрывает HTTP-клиент, процессов для чтения UUID нет.
Если atomic save уже начался, он может закончиться после close, но разрешение от
этого не появляется. Runtime нельзя передавать через fork/copy/pickle; новый процесс
создаёт новый client и снова требует сеть.

После истечения лицензии desktop обязан сохранять введённый текст/экспорт и дать
ранее принятой модели завершить сохранение результата, закрыв новые защищённые
действия. Эти операции подключаются следующим циклом; D04-03 не меняет редактор.

## Диск и платформа

license-activation.json содержит только schema_version, UUID лицензии и dv1 digest.
Повреждённый regular файл не сбрасывается автоматически. После успешного ввода ключа
его можно заменить; failed activation не меняет файл. Atomic save оставляет старую
либо целую новую identity; неопределённый ACK после rename требует повторной проверки,
а не выдачи доступа по предположению. DOCX/БД документов клиент не изменяет.

macOS: IOKit platform UUID, Windows: firmware SMBIOS>=2.6 UUID. Нет fallback на
имя компьютера/MAC/random ID. Сырой UUID сразу преобразуется существующей
platform-separated SHA256-функцией и не отправляется серверу. Изменение платы/UUID
может потребовать решения о переносе лицензии; автоматический перенос не реализован.
Это привязка штатного клиента, не аппаратная аттестация/защита от патча Python-кода.

HTTPX использует проверенный HTTPS, отключённые redirects/environment proxies,
соединение на одну попытку и bounded raw response. Явные injected clock/device/
transport/store предназначены для доверенной композиции и fixture tests, не HTTP
настроек пользователя. Fixture transport не подтверждает реальную TLS deployment.

Нативные macOS identity/clock доступны локальной приёмке. Windows firmware/storage
нуждаются в отдельном запуске на Windows; наличие synthetic ABI tests не заменяет
этот gate. Публичный сервер, установленное приложение, frontend и реальные веса ML
этим компонентом не объявляются готовыми.
