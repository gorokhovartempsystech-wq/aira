# D03-17E4C2 — effective review через API

3 ноября 2026. [Контракт](d03-17e4c2-contract.md) выполнен. Optional review API
использует E4B для чтения effective скрытий и C1 для команд hide/unhide. После
правки другого абзаца однозначно соответствующее замечание остаётся скрытым;
изменение самого фрагмента возвращает замечание в список. Unhide снимает все
соответствующие прежние решения. Чтение не записывает новые решения.

Добавлен explicit POST `/analysis-preferences/clear-hidden` с CAS и replay:
возвращает все скрытые замечания, сохраняя фильтры, исходные результаты и DOCX.
При превышении бюджета resolver это доступное восстановление без decode origins;
невалидный текущий результат остаётся ошибкой. Прежние raw endpoints неизменны.
Новый маршрут использует существующее ограничение запросов, без нового пула или
процесса. На V12 возвращает503 без миграции; default app без supervisor не получает
новых маршрутов. [API guide для фронтенда](docx-review-api.md) обновлён.
