# D02-05 — результат рабочей сессии DOCX

29 октября 2026. Реализован [контракт D02-05](d02-05-contract.md), часть F05/F10/F11 [текущего объёма](current-product-scope.md). **Независимый gate: 1149 тестов и 24 подтеста проходят**, Ruff и форматирование проходят. Сессия объединяет операции DOCX в последовательное редактирование с отменой, повтором и признаком несохранённых изменений. Это программный слой открытого документа; интерфейс и запись на диск ещё не подключены.

## Поведение

`ara.docx_package.session.DocxSession` открывает проверенные bytes DOCX и возвращает неизменяемый `SessionSnapshot` с текущим файлом, свежей проекцией, ревизией, признаком `is_dirty` и глубинами undo/redo. Настройки и возвращённые объекты отделены от внутреннего состояния. Даже обход frozen у ранее выданного DTO не повреждает сессию или её историю.

`apply` использует существующий D02-04 экспорт. Настоящая правка увеличивает ревизию, сохраняет прежний файл для отмены и удаляет ветку повтора. No-op оставляет историю и ревизию прежними. Undo/redo восстанавливают точные bytes прежних файлов; ревизия при этом продолжает увеличиваться. Команда со старой ревизией отклоняется, даже если отмена уже вернула прежнее содержимое. Ошибка, включая поздний сбой подготовки ответа, оставляет всё состояние нетронутым.

Начальная сохранённая отметка соответствует импортированному файлу. `mark_saved` подтверждает текущий файл после успешной внешней записи, не меняя ревизию или историю. Сравнение по точным bytes позволяет убрать `is_dirty` при возврате к сохранённому содержимому. Запоздалое подтверждение не сбрасывает свежие несохранённые изменения. Сам `mark_saved` не пишет файл и не выполняет автосохранение.

История ограничена количеством состояний и суммой размеров удерживаемых сжатых DOCX. При новой правке вытесняются самые старые undo-состояния; текущий файл сохраняется. Повторяющиеся bytes учитываются на каждую позицию истории. Слишком большой текущий файл отклоняется атомарно. Это бюджеты истории, а не гарантия предела всей памяти приложения или согласованный продуктовый лимит документа.

Код использует только стандартную библиотеку и память, без файлов, секретов, сети, БД, процессов, фоновых потоков и логирования содержимого. Существующие ограничения DOCX, форматирование, API/ML-контракты, миграции и зависимости не менялись.

## Оставшиеся границы

Сессия живёт только в памяти; команды одной сессии выполняются последовательно вызывающим кодом. Не реализованы хранение DOCX и восстановление после перезапуска, таймер автосохранения, снимки для анализа, интерфейс, структурные правки абзацев/таблиц, шаблон AIRA и реальная локальная модель. Исходник для долгосрочного хранения нельзя полагать сохранённым только в вытесняемой undo-истории. Будущее хранилище потребует отдельной ревизии записи, поскольку ревизия сессии начинается с нуля при каждом открытии. Следующий цикл автоматически не запускался.
