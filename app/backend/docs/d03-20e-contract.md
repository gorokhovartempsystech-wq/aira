# D03-20E — вставка изображений PNG/JPEG

9 ноября 2026. F05/F11/F12. Новая команда `insert_image` существующего редактора:
`{data_base64, alt_text?}`. Только переданные байты, без путей/URL/загрузки сети.
Статические PNG, baseline/progressive JPEG; 4 MiB, 20 млн пикселей — технические
границы декодирования запроса. Проверяется формат/структура контейнера;
это не OCR и не гарантия декодирования каждого повреждённого изображения.

Изображение размещается отдельным абзацем в позиции свёрнутого курсора с
сохранением обеих половин исходного абзаца. Размеры сохраняют пропорции и
вписываются в рабочую область раздела. Новый media part, внутренняя relationship
и content type создаются атомарно, без перезаписи прежних ресурсов. Повторная
вставка одинакового файла может использовать тот же media part. Один undo/redo
восстанавливает весь пакет и курсор. Альтернативный текст сохраняется в DOCX.

Пути: новые `_images.py`/`_image_package.py` в `docx_package/editor`; расширение
вставки блоков в `_objects.py` и `_session.py`; опциональные новые ZIP parts в
`structure/_package.py`; существующие commands/wire/schema/client protocol;
новые тесты и документация. Старые проверки, SQL, маршруты и зависимости не
меняются. Все прежние вызовы repack сохраняют старое поведение.

Проверки: PNG/JPEG, размеры/пропорции, исходные parts/relationships, точный
undo/redo, duplicate media, повреждённые/слишком большие запросы, неподдержанные
позиции, HTTP replay/save/reopen. Новые кнопки frontend не входят в этот патч.

Уточнение приёмки, согласовано Никитой 9 ноября в этом чате: сохранность alt text
и полный undo/redo проверяются отдельно от успешного анализа обычного изображения.
Существующая политика анализа с непустым alt text остаётся явным отказом
`unsupported_image_alternative_text`; E не меняет интерпретацию описаний.

Визуальная приёмка выявила несовместимость LibreOffice с префиксными новыми
Relationship/Override. Для новых записей применяется default namespace;
исходные metadata не перезаписываются. Отдельная регрессия воспроизводит дефект.
