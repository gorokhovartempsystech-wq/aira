# AIRA — AI Requirements Assistant

Локальное приложение для проверки требований в одном документе. Пользователь создаёт документ или импортирует DOCX, запускает проверку, разбирает замечания, вручную исправляет текст и проверяет его повторно. Итоговый DOCX содержит пользовательский текст без замечаний AIRA.

Учебный стартап команды С15, МФТИ, НИР 3.

## Текущий MVP

- Windows и macOS — целевые платформы; установка, лицензирование на одно устройство и совместимость с Word ещё требуют проверки.
- Один документ за проверку; вкладки не означают междокументный анализ.
- Замечания к формулировкам, повторы, возможные противоречия; вопросы при нехватке условий — в разработке.
- Ручные исправления и повторная проверка; фильтры и память скрытия — целевое поведение приложения.
- Локальный анализ, бюджет проверки 300 секунд с явным сообщением о частичном результате.
- В текущий объём не входят автоисправления, Merge, Confluence/Jira, PDF/OCR и командное облачное пространство.

## Что опубликовано

`engine/` содержит ML-движок, локальный браузерный прототип, обучение и экспериментальные проверки. `contracts/` — HTTP-контракт и примеры. `app/backend/` содержит проверенный backend с PostgreSQL, DOCX-редактором, сохранением/восстановлением и строгой проверкой ответов модели. Состав, 2704 tests +24 subtests и ограничения — в [handoff](app/backend/PUBLICATION.md). Реальная интеграция с текущим engine ещё требует отдельного адаптера.

Прототип не является готовым десктопным установщиком. Его экспериментальная проверка влияния правки сохранена для исследований и не расширяет согласованный MVP.

## Быстрый старт

```bash
cd engine
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-engine.txt -r requirements-test.txt
python -m pytest -q
# Указать путь к отдельно полученному пакету моделей
python -m aira_ml.proto --models /path/to/models-0.2m --port 8780
# Открыть http://127.0.0.1:8780
```

Рабочая конфигурация: rubert-tiny2 + pair2 + nli5, ONNX int8 на CPU, пакет около 402 МБ. Веса не входят в Git; наличие опубликованного Release проверяйте отдельно. Код интеграции описан в [app/README.md](app/README.md), запуск и исследования — в [engine/README.md](engine/README.md).

## Данные и качество

Синтетика — материалы для настройки, а не подтверждение гипотез. Набор v5 требует экспертной проверки. Нулевое число срабатываний на корпусе без полной разметки не доказывает отсутствие ошибок. Локальная LLM исследуется как дополнительный помощник; в основной конвейер не подключена.

Ключи, внешние корпуса, документы заказчиков, персональные данные, кэши и веса не публикуются. Правила работы — [CONTRIBUTING.md](CONTRIBUTING.md).
