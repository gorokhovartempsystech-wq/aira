# Как мы работаем

## Задачи

- Все задачи — в GitHub Projects, доска **AIRA**. Колонки: **Todo → In Progress → Done**
  (ревью — через открытый PR, его видно на карточке).
- Задача = issue в этом репозитории. Шаблоны: «Задача», «Баг», «Эксперимент (ML)».
- Метки по зоне: `engine`, `app`, `design`, `contract`, `research`, `nir`, `data`; по типу — `bug`.
- Срок и ответственный — у каждой задачи. Если задача больше 3 дней — дробим.

## Ветки и Pull Request

1. От свежего `main`: `git switch -c <кто>/<номер>-кратко` (`nikita/7-editor-paste`).
2. Коммиты — по-русски, по смыслу: «Движок: влияние правки возвращает confidence».
3. PR в `main`, в описании — `Closes #<номер>`: задача закроется при слиянии.
4. Ревью: владелец папки из `CODEOWNERS`. Изменения в `contracts/` — ревью **обеих** сторон
   (приложение и движок).
5. Сливаем, когда проверки (GitHub Actions) зелёные и ревьюер одобрил. Squash merge.
6. `main` защищён: прямые пуши и force-push запрещены.

## Контракт приложения и движка

- Источник правды — `contracts/engine-api.md` и `contracts/engine.schema.json`.
- Меняется только через PR с меткой `contract`. Ломающее изменение — новая версия API
  (`/v2/...`), старая работает, пока приложение не переедет.
- Примеры запросов и ответов в `contracts/examples/` — реальные ответы движка; тесты сверяют
  их со схемой.

## Данные и безопасность

- **Секреты** — только в `.env` (в `.gitignore`). Если ключ попал в коммит — сразу отозвать ключ,
  потом чистить историю.
- **Реальные документы компаний** (респонденты, пилоты, рабочие материалы) — никогда в репозиторий,
  в облачные LLM и в общие чаты. Только локально, у того, кому их дали.
- **Синтетические данные** — можно, с записью происхождения (`engine/data/spaces/gen/PROVENANCE.md`).
- **Публичные наборы** — с лицензией и атрибуцией.

## Встречи

- **Еженедельный созвон** 30 минут: что сделали, что мешает, план на неделю. Ведущий — по очереди.
- **Решения** — в `docs/decisions/` (один файл на решение: контекст, решение, последствия).
- **НИР:** дневник каждый спринт (раз в 2 недели) — у каждого свой, в папке проекта на Диске.
